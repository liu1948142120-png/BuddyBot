## 一、系统要求

| 项目 | 要求 |
|---|---|
| 芯片 | Apple Silicon（M1 / M2 / M3 / M4 系列）。**不支持 Intel 芯片的旧款 Mac** |
| 系统 | macOS 12 Monterey 及以上（建议 macOS 14+） |
| 网络 | 首次安装与自动更新需能访问 GitHub；日常使用访问 WorkBuddy 官方接口 |
| 磁盘 | 约 300 MB（程序 + 本地数据） |

> 不确定自己是什么芯片：点左上角  苹果菜单 →「关于本机」，看「芯片」一栏写的是 Apple M 系列即可。

## 二、安装（三种方式任选其一）

### 方式 A：pkg 安装器（推荐，最省事）

1. 下载 `BuddyBot-darwin-arm64-installer.pkg`；
2. 双击打开，按提示点「继续 → 安装」，输入开机密码授权；
3. 安装完成后在「启动台」或「应用程序」里找到 BuddyBot。

pkg 方式安装的应用已自动解除系统隔离标记，**后续打开不会再弹安全提示**。

### 方式 B：dmg 镜像安装

1. 下载 `BuddyBot-darwin-arm64.dmg`，双击打开；
2. 把 `BuddyBot.app` 图标拖入「应用程序」文件夹；
3. 弹出窗口点「完成」，首次打开需放行（见下文「首次启动」）。

### 方式 C：zip 便携包（免安装）

1. 下载 `BuddyBot-darwin-arm64.zip`；
2. 双击解压，得到 `BuddyBot.app`；
3. 可直接双击运行，也可拖入「应用程序」目录长期使用。

> 三种方式装的是同一个程序，效果完全一致，选顺手的即可。已装过旧版的，直接用新包覆盖安装即可升级，**本地账号数据不会丢失**。

## 三、首次启动

### 首次打开若提示「无法验证开发者」（zip / dmg 方式）

因为安装包未经过苹果公证，macOS 会拦截一次。处理方法（只需一次）：

1. **右键点击** `BuddyBot.app` → 选择「**打开**」；
2. 弹窗中再点「**打开**」；
3. 之后双击即可正常启动，不再提示。

若已经双击后被拦（提示「已损坏」或「无法打开」），打开「终端」执行一条命令即可解除：

```bash
xattr -dr com.apple.quarantine /Applications/BuddyBot.app
```

（pkg 安装的无需此操作。）

### 启动后界面

启动后进入主窗口，左侧为功能导航：仪表盘、账号、API 密钥、聊天、智能体、免费额度、插件、技能、指令、日志、设置等。底部菜单栏常驻图标，可随时唤出主窗口。

## 四、快速上手：添加账号

1. 左侧进入「**账号**」页；
2. 点「**添加账号**」→ 出现扫码登录窗口，用 WorkBuddy App 扫码授权；
3. 登录成功后账号出现在列表中，状态显示「在线」即正常。

**批量导入已有账号**（从别的电脑迁移或朋友分享的凭证文件）：
账号页 →「导入凭证」→ 选择 `.json` 凭证文件（可多选），导入后自动识别账号。

**查看积分余额**：账号列表每行有「刷新余额」按钮，点击即时查询；程序也会定时自动刷新。

## 五、核心功能使用

### 1. 全自动积分任务（本工具的核心价值）

进入「**设置 → 定时任务**」，开启需要的自动任务：

- **每日签到**：设定执行时间（如每天 09:00），到点自动完成；
- **保活**：定时保持账号活跃，防止长期不用被判休眠；
- **其他活动任务**：旅行、活跃地图、开学季、夜猫子、成长任务等，按活动开关；
- 任务完成情况可在「日志」页查看，配合通知推送使用更直观。

### 2. 多账号池

- 所有已登录账号自动组成账号池，仪表盘实时显示在线 / 冷却 / Token 状态；
- 某个账号 Token 失效会标记「需重新登录」，重新扫码授权或点「刷新余额」即可自动恢复；
- 「设置 → 账号池策略」可调单账号并发上限、熔断阈值与自动恢复。

### 3. 智能网关（把账号池变成 API）

1. 「**API 密钥**」页生成或查看根密钥；
2. 网关默认监听本机地址（「设置 → 网关服务」可改端口）；
3. 其他 AI 客户端把 API 地址指向 `http://127.0.0.1:<端口>` 并填入密钥，即可使用账号池，自动多账号分流、故障熔断、会话粘性；
4. 「**聊天**」页可先自测网关连通性；「**智能体接入**」页有一键接入各类客户端的配置模板；
5. 安全起见可开启「IP 白名单」，只允许指定地址访问网关。

### 4. 客户端切换

账号页选中某账号 →「切换」，WorkBuddy 客户端即以该账号登录，**无需重新扫码**。切换只更换登录凭证，不影响本地聊天记录等数据。

### 5. 统计与日志

- 「**仪表盘**」：账号池总览 + 累计积分消耗卡片；
- 「**Token 消耗 / 客户端消耗**」：消耗明细与趋势；
- 「**日志**」：请求日志与操作审计，全部本地留存。

## 六、自动更新说明

程序内置更新通道，**每 6 小时自动检查一次**新版本（v1.0.20 起）：

- 检测到新版后自动下载并**原地替换升级**，无需手动重新下载安装；
- 升级在后台完成，下次启动即是新版；
- 更新包来源为 GitHub Release，若网络访问 GitHub 困难，自动更新可能失败——不影响日常使用，可从分享渠道手动获取新版覆盖安装。

> 想立即检查更新：重启一次程序也会触发检查。

## 七、数据存放位置与备份迁移

macOS 版所有数据集中存放在：

```text
~/.buddybot/
├── config.json    # 程序配置
├── auths/         # 各账号登录凭证（敏感，勿外传）
├── store.json     # 运行数据（余额记录、任务状态、日志等）
└── ...
```

- **备份**：「设置 → 数据与备份」可一键导出配置；
- **整体迁移到新 Mac**：退出程序，把整个 `~/.buddybot` 文件夹拷贝到新电脑同一位置即可；
- **彻底卸载**：把 `BuddyBot.app` 移入废纸篓 + 删除 `~/.buddybot` 文件夹（删除后所有账号凭证与记录一并清除，不可恢复）。

> 多实例/测试场景可用环境变量 `BUDDYBOT_HOME` 指定其他数据目录。

## 八、常见问题 FAQ

**Q1：打开提示「无法验证开发者」或「已损坏」。**
右键 App →「打开」放行一次；或终端执行 `xattr -dr com.apple.quarantine /Applications/BuddyBot.app`（见第三节）。

**Q2：账号显示「需重新登录」。**
该账号 Token 已失效。点该行的「刷新余额」或重新扫码授权一次即可自动恢复，不用删号重加。

**Q3：积分余额和官网显示不一致？**
请确认程序为 **v1.0.20 及以上**——旧版查询接口的过滤条件会漏算部分套餐（例如差一个 500 分的包），v1.0.20 已修复。在账号页点「刷新余额」即可看到与官网一致的数值。

**Q4：自动更新一直不生效？**
更新包托管在 GitHub，国内网络直连时快时慢。更新失败不影响使用，等网络通畅时它会自动补上；也可以手动下载新版覆盖安装，数据不受影响。

**Q5：Intel 芯片的 Mac 能用吗？**
当前版本仅支持 Apple Silicon（M 系列）。Intel 机器暂无可用包。

**Q6：可以同时开多个程序实例吗？**
不可以。程序有单实例保护，重复启动会自动聚焦到已运行的窗口，这是为防止数据目录写冲突。

**Q7：换 Mac 或重装系统，账号要重新扫码吗？**
不用。按第七节把 `~/.buddybot` 整个文件夹迁移过去，所有账号凭证原样保留。

**Q8：程序是免费的吗？数据会上传吗？**
程序免费。所有数据（账号、凭证、日志）只存在你自己电脑上，不上传任何服务器；唯一的外部请求是查官方积分接口和检查 GitHub 更新。

## 九、安全与隐私说明

- 账号登录凭证以文件形式保存在本机 `~/.buddybot/auths/`，**请勿把该文件夹内容分享给他人**（等于交出账号）；
- 若需分享程序本体，只发安装包（pkg / dmg / zip），不要附带数据目录；
- 网关密钥请妥善保管，开启 IP 白名单可进一步收紧访问；
- 程序不含任何遥测上报。
