# BuddyBot 便携版 · 功能介绍

> 一款本地化的 WorkBuddy 多账号管理与智能网关工具，绿色免安装，数据全部保存在自己电脑上。
> 当前版本 v1.0.19 · 支持 Windows 及 macOS（Apple Silicon）

---

## 一、核心优势

1. **绿色便携，解压即用**
   免安装、免配置，解压后双击即可运行。所有数据（账号凭证、配置、日志）都保存在本地文件夹里，不注册、不上云、换电脑拷走文件夹即可迁移。

2. **多账号统一管理**
   支持同时挂载多个账号，形成账号池。每个账号的实时状态（在线 / 冷却 / Token 过期 / 需重新登录 / 已禁用）一目了然，支持批量查看余额与用量。

3. **全自动积分任务**
   内置定时任务引擎，自动完成每日签到、保活、旅行、活跃地图、开学季、夜猫子、成长任务等各类积分活动，定时刷新积分余额，任务完成后可推送通知。

4. **一键切换客户端登录**
   通过软件切换 WorkBuddy 客户端账号，无需反复扫码登录。切换只更换登录凭证，不动本地历史数据。

5. **内置智能网关**
   本地起一个统一的 API 网关，把账号池的能力以标准接口形式提供给其他客户端调用，自动在多账号间分流、熔断、恢复。

6. **应用内自动更新**
   内置更新通道，新版本发布后自动检测、自动升级，无需手动重新下载。

## 二、功能模块一览

### 概览与统计
| 模块 | 说明 |
|---|---|
| 仪表盘 | 账号池在线数、冷却数、Token 状态、请求量总览 |
| Token 消耗 | 积分消耗明细与趋势（签到 / 保活 / 任务等分类统计） |
| 客户端消耗 | 按接入的客户端分别统计用量 |

### 账号与凭证
| 模块 | 说明 |
|---|---|
| 账号管理 | 多账号增删、扫码登录、凭证导入、状态标记、余额刷新 |
| API 密钥 | 网关根密钥与子密钥管理 |
| 免费额度 | Ferry 免费额度通道配置 |

### 接入与扩展
| 模块 | 说明 |
|---|---|
| 聊天测试 | 网关连通性与模型对话自测 |
| 智能体接入 | 把账号池接入各类智能体客户端 |
| 插件中心 / 技能市场 / 提效指令库 | 能力扩展与常用指令集合 |
| 日志查看 | 请求日志、审计日志全记录，可追溯 |

### 安全与策略（设置页）
| 模块 | 说明 |
|---|---|
| 网关服务 | 监听地址、根密钥、凭证目录 |
| 安全与访问 | 只读模式、IP 白名单 / 黑名单 |
| 账号池策略 | 单账号最大并发、熔断阈值、自动恢复 |
| 会话粘性 | 同一会话固定同一账号，粘性有效期可调 |
| 定时任务 | 每日签到时间、定时刷新、任务完成推送 |
| 增强功能 | 保持系统唤醒、注入面板 |
| 数据与备份 | 导出配置、一键备份 |

## 三、与原版相比的改进（本便携版定制点）

1. **自建更新通道** —— 版本由本仓库统一发布，升级节奏自己掌控；
2. **「需重新登录」状态自动修复** —— 重新授权 / 刷新余额后自动恢复正常状态，不再误报；
3. **积分消耗统计卡片** —— 仪表盘直观展示累计消耗；
4. **客户端切换稳定性修复** —— 切换账号更可靠；
5. **macOS 版本支持** —— 官方未提供 Mac 包，本版本补齐（Apple Silicon）。

## 四、安装方式

**Windows**：解压后双击 `BuddyBot.exe` 即可使用。

**macOS（Apple Silicon）**：
- 推荐：双击 `BuddyBot-darwin-arm64-installer.pkg` 按提示安装，装完无安全提示；
- 备选：解压 `BuddyBot-darwin-arm64.zip`，将 `BuddyBot.app` 拖入「应用程序」，首次打开右键 →「打开」放行。
